# Aura Music Studio

AI-assisted music production workspace for score-driven, realistic backing tracks.

This repository is intended to orchestrate ACE-Step 1.5 / ACE-Step Studio for neural music rendering, with score-derived timing and arrangement data, realistic band instrumentation, harmony vocals, stem export, and final mastering.

## Current target project
- Tempo: 96 BPM
- Meter: 4/4
- Source structure: 107-measure uploaded guitar/tab score
- Goal: realistic backing track with drums, bass, acoustic guitar, electric rhythm guitar, lead guitar countermelody, piano, synths, strings/pads, percussion, and backing harmony vocals for a separate lead vocal.

## Rendering requirement
Use an NVIDIA CUDA GPU. ACE-Step Studio recommends 12 GB VRAM minimum for XL models, with more VRAM preferred for higher-quality models.
