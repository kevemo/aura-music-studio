# Chat 4 Brand Authority

Effective immediately for Chat 4 and the Aura Sec subsystem, the authoritative public-facing master brand is:

# Elevate Souls Productions Content Creation Command Center

**Powered by Aura AI**

Aura Sec is a separately purchasable security product/service within this ecosystem unless the security product itself is renamed later.

## Integration rule

Chat 4 must use this wording in new public-facing security copy, product documentation, Security Center surfaces and merge notes.

The repository currently contains legacy public names from earlier build phases. Because multiple parallel build chats are modifying shared application branding, Chat 4 should not perform a broad repository-wide search/replace that would create avoidable conflicts. The shared/core branding migration should update the central brand constants once, after which Aura Sec should inherit the master site name automatically where it uses the shared branding layer.

## Legacy-name handling

Older names may remain temporarily in:

- repository/package identifiers;
- historical documentation;
- compatibility environment variables;
- existing routes/cookies/database identifiers;
- branches created before this branding decision.

Those identifiers do not define the current public product brand and should be migrated only when doing so is safe and backwards-compatible.
