# Pulsar-Frequency House — Living Competitive Feature Benchmark

**Product:** Pulsar-Frequency House  
**Powered by:** Elevate Souls Productions & Aura AI Systems  
**Tagline:** For Professional Creation Beyond The Cosmos

This document is a living feature-class benchmark for product planning. It must be updated as competitors change. It is **not** permission to copy proprietary source code, UI layouts, protected assets, prompts, model weights or trade dress. Pulsar-Frequency House should meet or exceed useful workflow capabilities through original implementation.

## Product objective

Pulsar-Frequency House is designed as one integrated professional creation ecosystem rather than a collection of disconnected generators. It should combine best-in-class capability classes across AI music, DAW production, voice, image/poster creation, video generation/editing, social management, creator-business workflows and Aura-guided cross-media editing.

## Core benchmark set

### AI music generation / song transformation
Benchmark capability classes from services such as:
- Suno
- Udio
- Donna AI / Donna-style mobile AI music products
- Stable Audio and other current generative-audio systems

Pulsar target: prompt/lyrics/reference creation, uploaded-audio continuation, covers/remixes where lawful, section-level regeneration, stem-aware editing, voice/performance control, Song DNA, versions, commercial project workflow and direct Aura revision.

### DAW / recording / mixing / mastering
Benchmark capability classes from services such as:
- BandLab
- Soundtrap
- Ableton/Logic-style professional DAW workflows where browser implementation is practical
- LANDR and other mastering/production tools

Pulsar target: browser multitrack timeline, recording, takes/comping, audio + MIDI/control lanes, waveform editing, gain/pan/FX, automation, routing, stem separation, audio-to-MIDI controls, mastering, version history and an integrated persistent player.

### Video generation and professional editing
Benchmark capability classes from services such as:
- CapCut
- Runway
- Kling
- Luma
- Pika
- Adobe video/Firefly workflows
- current leading text/image/video generation systems

Pulsar target: text/image/reference-to-video, Music Video Director, scene/shot timeline, keyframes, transitions, captions, beat/lyric sync, auto reframe, masks/cutouts, effects, colour tools, motion controls, reusable characters/assets, non-destructive versions and direct Aura editing of individual scene properties.

### Image, artwork and poster creation
Benchmark capability classes from services such as:
- Canva
- Adobe Express / Firefly
- Midjourney-class image generation
- current leading image editing/generation systems

Pulsar target: image generation, posters, cover art, campaign creatives, editable variants, reference-aware generation, background/object replacement, resizing/adaptation, brand kits, templates, text/layout tools and Creative DNA versioning.

### Social media management / creator operating system
Benchmark capability classes from services such as:
- Rella
- Later
- Buffer
- Hootsuite
- Metricool
- Sprout Social
- Canva social scheduling

Pulsar ESP target: private ESP-only Social Houses, content calendar, campaign board, tasks, notes, platform variants, approvals, secure provider connections, publishing queue, analytics ingestion, Aura recommendations, social inbox where provider APIs permit, creator niche context and creator/agent/owner role separation.

### Aura differentiation
Pulsar must go substantially beyond benchmark tools by making Aura the cross-media operating intelligence:
- one conversation can understand the member's project, song, stems, image, video, campaign and social performance context;
- members can ask Aura by text or voice to change a precise part of a creation;
- edits are non-destructive and version-aware;
- Aura can move from song creation → cover art → music video → poster/social variants → publishing plan without rebuilding context;
- ESP members receive niche-aware creator-business guidance unavailable to ordinary public subscribers;
- Mary/Kev owner controls remain separate from creator and agent permissions.

## Commercial entitlement baseline

Current authoritative packaging direction:

| Capability | Free | Basic £4.99/month | Pro £9.99/month |
|---|---:|---:|---:|
| Image/poster generations | 5/day | 10/day | Unlimited |
| Save image/poster outputs | Yes | Yes | Yes |
| Download image/poster outputs | Yes | Yes | Yes |
| Music/video playback | Yes where creation/preview is available | Yes | Yes |
| Music/video downloads | No | Yes | Yes |
| Advanced/pro production features | Limited | Expanded | Full enabled stack |

Server-side APIs must enforce these entitlements; UI labels alone are insufficient.

## Continuous benchmark rule

Before completing any major subsystem, compare it against current leaders in that feature class and update this document when a meaningful competitive capability has emerged. The product goal is not superficial feature count: Pulsar should provide a more coherent end-to-end professional workflow, with stronger editability, project memory, cross-media continuity, truthful provider state and Aura-guided execution.
