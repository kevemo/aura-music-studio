# Video Product Requirements

The Live Sound Studio video surface must behave as one integrated creative product rather than a collection of disconnected provider buttons.

## User-facing entry points

- **Generate Video** from text, image, or existing video.
- **Make Music Video** from a completed song/project.
- **Make Lyric Video** from a final master plus lyrics/timing.
- **Animate Cover Art** from release artwork.
- **Make Social Clip** from a selected hook/section.
- **Create Visualizer** from any studio master.

## Required controls

- prompt and negative prompt;
- portrait, landscape, and square target;
- duration;
- quality/cost preference;
- provider choice or Aura Auto Route;
- reference asset selection;
- platform preset;
- project attachment;
- continuity instructions;
- clean vs lyric/captioned output.

## Required output behavior

- generated clips remain attached to the originating project;
- generation job history is persistent;
- provider/model provenance is recorded;
- failures surface real provider errors in safe user language;
- users can retry or create variants without destroying previous outputs;
- final exports use the studio master audio where requested;
- ordinary users never gain access to ESP-only Creator Network content through video routes.

## Entitlement principle

Deterministic local tools such as visualizer rendering can be broadly available according to plan. Cost-bearing generative video must have explicit quota/credit enforcement so one account cannot create uncontrolled provider spend.
